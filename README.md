## 韩国 TikTok 为什么要先看 IP 属性

机房 IP 的问题不在速度快慢，而在平台把它识别成谁。韩国 TikTok 的判定大致分三层：ASN 是否指向韩国本土运营商、这个 IP 在数据库里登记为机房还是家庭宽带、以及 IP 的风险分和历史行为。机房 IP 即使物理机就在首尔，ASN 指向云服务商，第一层就被划到“非本地用户”，后面内容做得再好也难拿到正常起始流量。

“原生 IP”和“住宅 IP”经常被当成一回事，实际是两个条件。

- **原生**：IP 段由韩国本土运营商分配，ASN 指向韩国 ISP，不是从别的地区宣告过来伪装的。
- **住宅**：IP 属于家庭宽带段，在 IP 数据库里登记为 ISP 而不是数据中心。

“双 ISP”指的是数据库记录里带家庭宽带属性，能通过两家 ISP 属性的交叉校验。WePC 韩国线用的是世宗电信，官方描述是双 ISP 住宅 IP，部分检测平台识别为家宽网络。

独享 IPv4 是底层要求。一台机器一个 IP，不和别人共用。共享 IP 上只要有人跑过灰产或大量注册，整段 IP 的风险分会被拉高，你花钱买的住宅属性也就废了一半。

## 开通后先做这六项验证

不管买哪家韩国住宅 IP，机器到手别急着长期用，按顺序跑一遍：

1. **查 ASN**：ipinfo.io 或 ip.sb 看归属，应该是韩国本土 ISP（世宗电信），不是云服务商。
2. **查风险分**：scamalytics.com 输入 IP，住宅 IP 通常在 10~25 之间。分数偏高说明这个 IP 被大量使用过。
3. **看 TikTok 判定**：发一条测试视频，看推荐流是韩语内容还是其他地区内容。这一步比任何数据库查询都直接。
4. **看流媒体 region**：登录 Netflix 或 Disney+，确认显示韩国区。
5. **测三网**：ping 和 traceroute 分别跑电信、联通、移动方向，确认电信移动直连、联通是否绕路。
6. **测带宽**：speedtest 跑一遍，看实测是否接近标称的 100Mbps。

任何一项不达标，在退款或换 IP 窗口内处理掉，别拖到窗口关闭之后。

## 常见问题

**韩国原生 IP 和住宅 IP 是一回事吗？**

不是。原生只看 ASN 是否指向韩国本土运营商，机房 IP 也可以是原生的。住宅进一步要求 IP 属于家庭宽带段，在风控模型里更接近真实家庭用户。WePC 韩国线标的是双 ISP 住宅属性，两个条件都满足。

**为什么机房 IP 会 0 播放？**

TikTok 会把 ASN 指向数据中心、IP 段被大量账号使用过的流量归为非本地用户，起始推荐池很小。表现出来就是发出去几小时播放量停在个位数。

**512MB 内存能装 Windows 吗？**

资料里这档标注的系统是 Linux。512MB 跑 Windows 会非常吃力，即便装上也基本不能用。需要 Windows 的话，至少要 2GB 内存起步的方案。

**联通用户能做直播吗？**

资料普遍提到联通线路绕路，直播建议搭配中转。电信和移动用户直连表现更好。用联通的话，先测实际延迟再决定要不要加中转。

**一台机器能挂几个 TikTok 账号？**

这档是单 IP 加 512MB 内存，建议一机一号。多账号矩阵需要更多内存跑独立浏览器环境，也需要多个 IP，这档撑不住。
